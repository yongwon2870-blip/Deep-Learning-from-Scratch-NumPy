# 1. 신경망 (Neural Network) - 순전파와 활성화 함수
activation_funcs.py
neuralnet_forward.py

이 챕터에서는 다층 퍼셉트론(MLP)의 순방향 연산(Forward Propagation)을 넘파이(NumPy) 배열의 행렬 곱셈으로 구현하고, 활성화 함수를 시각화함.

1) 활성화 함수 (Activation Functions)
단순한 선형 연산(행렬 곱셈)만 반복하면 신경망을 깊게 쌓는 의미가 없으므로 이를 해결하기 위해 입력 신호의 총합을 출력 신호로 변환하는 비선형 활성화 함수를 구현. (`activation_funcs.py`)

* Step Function (계단 함수): 0을 경계로 출력이 0 또는 1로 갑자기 바뀜.
* Sigmoid (시그모이드 함수): 자연상수 e를 사용하여 입력을 0.0과 1.0 사이의 매끄러운 실수 값으로 변환.
* ReLU (Rectified Linear Unit): 입력이 0을 넘으면 그대로 출력하고, 0 이하이면 0을 출력. 최근 딥러닝에서 가장 널리 사용.

  2) 다차원 배열의 행렬 곱셈 (Matrix Multiplication)
신경망의 각 층(Layer)을 지날 때마다 발생하는 연산을 파이썬의 `for` 반복문이 아닌, 넘파이의 행렬 곱셈 연산자 `@`을 사용하여 한 번에 계산하도록 구현. (`neuralnet_forward.py`)

* 수식: A = XW + B
    * X: 입력 데이터
    * W: 가중치 (Weight)
    * B: 편향 (Bias)
    * A: 연산 결과

  3) 데이터 형태(Shape) 변화 추적
다차원 배열의 연산에서 가장 중요한 것은 행렬의 차원 크기(shape)를 일치시키는 것. 3층 신경망을 통과하는 동안 데이터의 형태가 어떻게 변환되는지 코드로 직접 추적.

* 입력 데이터 (X): shape `(2,)`
* 1층 통과 후 (Z1): 가중치 `W1` `(2, 3)`과 곱해져 shape `(3,)`으로 변환
* 2층 통과 후 (Z2): 가중치 `W2` `(3, 2)`와 곱해져 shape `(2,)`로 변환
* 최종 출력 (Y): 가중치 `W3` `(2, 2)`와 곱해져 최종 shape `(2,)`로 출력

행렬의 곱셈 규칙에 따라 앞 행렬의 열 개수와 뒤 행렬의 행 개수가 일치해야만 연산이 가능하며, 이 규칙을 통해 신경망의 노드 개수를 통제.

# 2. 신경망 학습 (Training Neural Networks)

numerical_gradient.py
gradient_descent_viz.py
train_neuralnet_basic.py

이 챕터에서는 신경망이 데이터로부터 학습하여 최적의 가중치(Weight)와 편향(Bias) 매개변수를 자동으로 찾아내는 원리를 NumPy로 구현.

  1) 손실 함수 (Loss Function)
신경망 성능의 '나쁨'을 나타내는 지표인 손실 함수를 구현하여, 현재 모델의 상태를 정량적으로 평가. (`numerical_gradient.py`)

* 교차 엔트로피 오차 (Cross Entropy Error): One-hot encoding된 정답 라벨에 대해, 정답일 때의 예측 확률이 1.0에 가까워지도록 오차를 계산.
* 미니배치(Mini-batch) 처리: 데이터 1장당 평균 오차를 구하기 위해, 수만 개의 전체 훈련 데이터 중 일부를 무작위로 뽑아(배치) 효율적으로 학습하는 기능.

  2) 수치 미분과 기울기 (Numerical Gradient)
모든 가중치 매개변수에 대해 손실 함수의 값을 조금씩 변화시켜 기울기(Gradient)를 구하는 수치 미분을 다차원 배열 탐색기(`np.nditer`)를 활용하여 구현. (`numerical_gradient.py`)

* 가중치 W의 원소를 아주 작은 값(h)만큼 변화시켰을 때, 손실 함수 L이 얼마나 변하는지(편미분)를 계산하여 가장 오차가 빠르게 줄어드는 방향을 탐색.

  3) 경사 하강법 시각화 (Gradient Descent)
학습률(Learning Rate)이라는 하이퍼파라미터가 모델 학습에 미치는 영향을 실험하고, 점이 오차의 최솟값을 찾아 이동하는 궤적을 `matplotlib`으로 시각화. (`gradient_descent_viz.py`)

* 적절한 학습률: 점이 부드럽게 최솟값(원점)으로 수렴.
* 너무 큰 학습률: 오차가 줄어들지 않고 오히려 발산하여 화면 밖으로 튕겨 나간다.
* 너무 작은 학습률: 거의 갱신되지 않고 초기 위치 주변에 정체.

  4) 2층 신경망 전체 훈련 루프 (Training Loop)
앞서 만든 부품들을 조립하여, 미니배치 추출 -> 기울기 산출 -> 매개변수 갱신 -> 오차 기록의 과정을 10,000번 이상 반복하는 훈련 루프를 완성. (`train_neuralnet_basic.py`)

* 에폭(Epoch)이 진행될수록 오차(Loss)가 부드럽게 하강하고, 훈련 및 테스트 데이터에 대한 정확도(Accuracy)가 90% 이상으로 동반 상승하는 것을 확인. (오버피팅 방지 검증 포함)

# 3. 오차역전파법 (Backpropagation)

backprop_test.py
layers.py 
gradient_check.py

이 챕터에서는 신경망의 학습 속도를 획기적으로 높이기 위해, 미분을 수치적으로 계산하는 대신 해석적(수학적)으로 계산하여 연쇄 법칙(Chain Rule)으로 전달하는 오차역전파법을 구현.

  1) 계산 그래프와 연쇄 법칙 증명
복잡한 수식을 단순한 노드(Node)와 에지(Edge)로 분해하는 계산 그래프를 이용해 역전파의 원리를 증명. (`backprop_test.py`)

* 덧셈 계층 (AddLayer): 미분값이 항상 1이므로, 상류에서 넘어온 오차(Gradient)를 하류로 그대로 통과.
* 곱셈 계층 (MulLayer): 순전파 시 입력되었던 두 값을 서로 뒤바꿔 곱한 뒤 하류로 흘려보냄. (값을 기억하기 위한 내부 변수 `self.x`, `self.y` 사용)

  2) 활성화 함수 계층 구현
신경망의 비선형성을 담당하는 활성화 함수들을 오차역전파법을 지원하는 모듈화된 클래스 형태로 구현. (`layers.py`)

* ReLU 계층: 순전파 때 0 이하로 차단되었던 위치를 마스크(`self.mask`)로 기억해 두었다가, 역전파 때 해당 위치로 흐르는 오차 피드백도 0으로 차단.
* Sigmoid 계층: 순전파 출력값(`y`)만을 이용하여 역전파 미분값을 $y(1-y)$ 형태로 간단하게 계산하도록 최적화.

  3) 행렬 연산과 출력 계층 구현
다차원 배열의 형상(Shape)을 유지하면서 오차를 계산하는 핵심 계층들을 구현. (`layers.py`)

* Affine 계층: 행렬 곱셈의 역전파는 전치 행렬(Transposed Matrix)을 사용해야 한다는 수학적 규칙을 코드로 표현. 원본 형상을 복구(`reshape`)하는 기능도 포함하여 다차원 데이터를 안전하게 처리.
* Softmax-with-Loss 계층: 신경망의 추론 결과(Softmax)와 실제 정답(Cross Entropy Error) 간의 오차를 계산합니다. 예측값(y)과 정답(t)의 차이인 (y - t)라는 매우 깔끔한 수식으로 미분 결과가 도출됨을 확인

  4) 기울기 확인 (Gradient Check)
수치 미분(단순하지만 느리고 오차가 있음)과 오차역전파법(복잡하지만 빠르고 정확함)으로 구한 각각의 미분값을 비교하는 테스트를 수행. (`gradient_check.py`)

* 결과: 두 방식으로 구한 기울기 차이가 무시할 수 있을 만큼 매우 작은 값(1e-9 수준)으로 일치함을 확인하여, 복잡한 역전파 코드가 수학적으로 오류 없이 완벽하게 짜였음을 증명.

# 4. 학습 관련 기술들 (Optimization & Regularization)

optimizer_analysis.py
weight_init_compare.py
dropout_effect.py

이 챕터에서는 기본적인 신경망의 성능 한계를 극복하기 위해 실무에서 필수적으로 사용되는 가중치 갱신 최적화 기법, 가중치 초기화 전략, 그리고 과적합 억제 기술을 구현 및 검증

  1) 매개변수 갱신 기법 (Optimizers)
단순한 확률적 경사 하강법(SGD)이 가진 지그재그 탐색의 비효율성을 개선하는 세 가지 고급 최적화 알고리즘을 모듈화. (`optimizer_analysis.py`)

* Momentum: 과거의 이동 속도를 기억하여 기울기 변화에 관성을 부여함으로써 부드럽고 빠른 탐색 지원.
* AdaGrad: 매개변수의 과거 갱신 기록을 제곱하여 누적하고, 많이 갱신된 변수는 학습률을 낮추어 정밀하게 탐색.
* Adam: Momentum(방향 관성)과 AdaGrad(보폭 제어)의 장점을 수학적으로 융합한 현대 딥러닝의 표준 최적화 기법 구현.

  2) 가중치 초깃값 비교 실험 (Weight Initialization)
은닉층을 5개로 깊게 쌓은 신경망에서, 가중치 초기값에 따른 데이터(Activation)의 분포 변화를 히스토그램으로 시각화하여 문제 분석. (`weight_init_compare.py`)

* 실패 사례 분석: 가중치 표준편차가 1일 때는 데이터가 양극단(0과 1)으로 몰리는 기울기 소실(Gradient Vanishing)이 발생하고, 표준편차가 0.01일 때는 데이터가 중앙에 몰려 다수의 뉴런이 동일한 값을 출력하는 표현력 제한 문제가 발생함을 증명.

* 해결책 적용: Sigmoid 같은 선형 활성화 함수에는 노드 수의 제곱근에 반비례하는 Xavier 초깃값을, 비선형인 ReLU 함수에는 분산을 두 배로 키운 He 초깃값을 적용하여 층이 깊어져도 데이터가 고르게 분포하도록 개선.

  3) 과적합 억제: 드롭아웃 (Dropout)
훈련 데이터에만 지나치게 적응하는 과적합(Overfitting) 현상을 막기 위해, 학습 시 은닉층의 뉴런을 무작위로 삭제하면서 학습하는 드롭아웃 기법 구현. (`dropout_effect.py`)

* `train_flg` 변수를 활용하여, 훈련 시에는 임의의 마스크(`self.mask`)로 노드를 차단하고 평가(Test) 시에는 모든 노드를 사용하되 출력 스케일을 보정하는 논리를 적용.

# 5. 합성곱 신경망 (Convolutional Neural Network)

layers_conv.py 
simple_convnet.py 
train_convet.py
visualize_filter.py

이 챕터에서는 이미지의 공간적 특성(픽셀 간의 상하좌우 관계)을 파괴하지 않고 패턴을 추출하는 합성곱 신경망(CNN)을 구현. 

  1) 합성곱 및 풀링 계층 (Layers)
다차원 데이터를 효율적으로 처리하기 위해 `im2col` 기법을 적용하여 행렬 연산 속도를 극대화. (`layers_conv.py`)

* im2col 기반 합성곱 (Convolution): 4차원 이미지 텐서와 필터 텐서를 각각 2차원 표로 전개한 뒤 행렬 곱셈을 수행하고, 다시 4차원으로 복원하는 논리 구조를 구현했습니다. 이 방식을 통해 Python `for` 반복문의 병목을 없애고 연산 속도를 비약적으로 향상시킴.

* 풀링 (Pooling): 최대 풀링(Max Pooling)을 구현하여 데이터의 공간 크기를 축소시키고 미세한 위치 변화에 흔들리지 않는 견고성(Robustness)을 확보. 역전파 시에는 `argmax`를 이용해 순전파 때 선택된 최댓값 위치로만 오차를 전달.

  2) CNN 아키텍처 조립 (SimpleConvNet)
이전 챕터에서 만든 다층 퍼셉트론(MLP)의 뼈대를 활용하여 `Conv-ReLU-Pooling-Affine-ReLU-Affine-Softmax` 구조의 실전적인 CNN 모델을 완성. (`simple_convnet.py`, `train_convnet.py`)

* 구조적 차이점 분석: 기존 완전연결 계층이 가진 '공간 정보 파괴', '역할의 혼재', '과도한 가중치 파라미터' 문제를 CNN이 어떻게 **형태 유지, 특징 추출과 분류의 분업화, 가중치 공유(Parameter Sharing)**로 해결하는지 코드 수준에서 확인.

  3) 필터(가중치) 시각화 검증 (Filter Visualization)
인공지능이 스스로 특징(Feature)을 찾아내는 과정을 증명하기 위해, 1층의 합성곱 필터 가중치를 이미지로 렌더링하는 시각화 코드를 작성. (`visualize_filter.py`)

* 학습 전: 초기화된 무작위 난수에 의해 필터가 불규칙한 노이즈(Noise) 상태임을 확인.
* 학습 후: 오차역전파법을 거치며 필터들이 가로선, 세로선, 대각선 등 특정 선형 패턴(Edge)에 반응하도록 물리적으로 갱신되었음을 시각적으로 증명.
